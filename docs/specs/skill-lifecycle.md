# 技能生命周期

初版：2026-10-21；当前契约更新：2026-10-27。服务于 W1–W3 的可复用编码流程；真实模型使用效果单独验收。

## 行为契约

一个技能是带名称、描述与正文的 Markdown 操作手册。**目录在本地注册，模型按需检索，正文临时激活。** 启动时不把全量技能名称、用途和路径放入模型上下文，只保留简短的 `[SKILL LIFECYCLE]` 发现与激活规则。静态注册不代表正文激活，显式 `activate` 配置仅作为兼容的临时预装入口。

目录支持 `<name>/SKILL.md`、`<name>.md` 和三级分类，保留简单 `name:` / `description:` 头及 `---` frontmatter。目录和状态由 Python `SkillManager` 管理，Ink 与 Agent 工具共用；Ink 保留全量目录、来源和扫描诊断。

| 阶段 | 触发 | 模型上下文 |
|---|---|---|
| 发现与注册 | 启动、每次任务开始、`/skills refresh`、`list_skills` | 目录保留在程序中；系统分区只有简短技能入口 |
| 按需检索 | Agent 调用 `list_skills(query, limit)` | 工具结果提供有限名称与短摘要，不带完整路径 |
| 激活 | Agent 按任务选择 `load_skill`，也可 `/skills activate` | 下一次请求加入临时正文、来源与资源路径说明 |
| 使用 | 模型按当前技能步骤提出普通工具调用 | 正文不随历史压缩丢失；写入和执行照常审批 |
| 卸载 | 使用结束时 `unload_skill`；每轮结束、暂停、取消或错误统一兜底，也可手动卸载 | 移除临时正文；注册目录和文件继续保留 |

默认发现 12 个项目技能根和 14 个用户技能根，覆盖本项目、跨工具共享及常见编码工具目录，完整路径见[使用指南](../USAGE.md)。本机只扫描这些标准根，不遍历整个用户目录或插件缓存；支持 `.system` 分类及标准技能根间的符号链接，排除脚本与参考资料目录。每次 `list_skills` 重新扫描磁盘，新增、修改和删除立即反映在结果中。

配置默认 `.vibe/skills.json`，`VIBE_SKILLS_CONFIG` 可覆盖；字段为 `paths`、`discover`、`disabled`。`paths` 注册额外来源并优先于项目和本机同名项；`discover: false` 只保留显式来源。相同真实文件重复出现时去重，异源同名诊断。单文件来源只授权该文件，不能扩大为其父目录。`VIBE_SKILLS_HOME` 覆盖本机目录基准，测试使用临时值隔离个人技能。

单文件最多读取 256 KiB，拒绝目录和 FIFO 等非普通文件。激活内容包含元信息最多 64,000 字符，超出时明确拒绝；本地目录摘要最多 600 字符。上限修正依据本机 112 份唯一技能文件的大小统计：37 份超过 8 KiB，最大 43,255 字节；原 8k 上限会挡住正常技能。Frontmatter 支持简单标量和 `description` 的 `|` / `>` 多行块，不解析任意 YAML 结构。

模型侧 `list_skills(query="", limit=5)` 按名称和描述关键词匹配，准确名称也可直接用于 `load_skill`。单次默认最多 5 条、上限 10 条，每条摘要最多 120 字符，整次结果最多 800 个估算 tokens；不附完整源路径，扫描错误只返回数量，未知名称错误不枚举全部技能。无匹配时提示更换关键词，可尝试英文描述中的词；不做语义翻译。查询结果进入工具历史并沿用现有压缩。Ink `/skills` 与 `/skills refresh` 保留完整目录与诊断，不套用模型查询的返回上限。

旧 `activate` 配置仅兼容为启动临时预装，刷新不重放，首轮结束同样清理；新示例不使用该字段。运行中的激活与卸载不改写注册来源；重启、`--continue` 与下一轮重新发现本地目录，需要正文时重新激活。

## 上下文与权限

技能入口放入 `skills` 系统片段；目录规模不增加该片段的占用。技能正文放入可替换的系统片段，并在上下文快照中分别记录 `active_skill` 及文件来源；资源相对路径和释放规则的详细说明随激活正文提供。每轮模型请求只同步入口和激活项，全量目录不注入系统上下文。管理命令不产生模型调用或任务消息；激活与卸载工具只返回状态回执，防止卸载后正文通过工具历史重新注入。历史回执不代表当前激活，只有当前 `[ACTIVE SKILLS]` 生效。旧版工具正文在模型历史及 `recall` 读取时转换成回执，原始会话日志不改写。

卸载保证停止注入受管理正文，不等于清除此前生成的答案、摘要、执行结果或外部模型的知识。技能不注册任意 Python 函数，不自动运行脚本；实际动作继续使用原有工具和 `ApprovalGate`。

异步技能工具先在候选状态中扫描，只有成功且未取消才提交。扫描线程超时后即使继续结束，也不能迟到激活或改写当前目录。

公共 `Agent.run()` 统一 `finally` 清理临时状态，包含模型循环前的配置错误、消息回调和 trace 回调异常。清理只改内存，不读取配置、不调用模型。请求快照保留实际已发送内容，不在清理时替换本轮回放；下一次请求或显式装载快照会反映清理结果。
