## 布局与取舍

采用终端全屏模式，退出恢复原终端。界面保持三段：

```text
项目名 / 路径                         模型 / 会话 / 演示模式
┌ 对话 ────────────────────────────────────────────┐
│ 空闲：任务示例与操作引导                           │
│ 对话：用户、助手、Markdown 与代码                 │
│ 工具：调用、目标、执行状态、摘要与详情入口         │
│                                                  │
└──────────────────────────────────────────────────┘
┌ 输入任务 ────────────────────────────────────────┐
│ 多行草稿与可见光标                                │
└──────────────────────────────────────────────────┘
运行状态 / 真实任务预算与上下文 / 当前可用快捷键
```

布局按终端行列分配，正文使用终端默认前景，保留系统背景；提供 `system`、`light`、`dark` 语义配色。重要信息同时用文字与样式区分，不靠低对比度灰色和颜色单独表达状态。浅色与深色都需要检查。

中央阅读区可翻页，回看时新内容不抢滚动。工具调用与结果更新同一条记录，默认收起长参数和输出，完整内容在详情页查看。审批独占阅读区，预览可翻页，明确一次允许、拒绝和取消；粘贴文本不能被当作批准按键。

## 本轮行为

- `Enter` 发送，`Ctrl+J` 换行，支持终端可识别的 `Shift+Enter`。粘贴多行保留为草稿，不自动发送。
- 上下键在多行内容中移动；到首末行边界时浏览输入历史，并能返回原草稿。中文、emoji 与组合字符按 grapheme 编辑，宽度按终端单元格计算。
- 运行时可编辑草稿，尚不支持将草稿提交为运行中纠偏。审批与详情聚焦时输入区不消费键盘和粘贴。
- `PgUp/PgDn` 翻阅对话或当前面板；`Ctrl+Home/End` 回到对话首尾；面板内 `Home/End` 翻到首尾。回看时显示位置与返回最新内容的提示。
- `Tab` 选择本会话已发生的工具，`Ctrl+O` 打开完整参数和输出，`Escape` 返回。输入 `/` 时 `Tab` 用于命令补全。
- `/help` 显示操作说明，`/cost` 查看后端提供的本轮用量，`/tools` 浏览已发生工具调用，`/theme system|light|dark` 切换配色，`/quit` 退出。
- `Ctrl+C` 取消当前任务，空闲时退出；`Ctrl+Q` 退出并等待后端清理。未知结果始终标明，取消不表示撤销。
- 状态栏读取真实 `metrics` 事件：本轮累计 tokens、上限、是否估算、当前上下文 tokens / 窗口、计划记录和费用。未知值留空或标未知，0 总预算表示不限；压缩不会重置累计消耗。
- 后端 stderr 通过界面提示呈现，不能直接把日志写进全屏布局；启动失败保留具体原因。

Markdown 先覆盖标题、列表、强调、行内代码、围栏代码和链接的可读呈现；不以完整浏览器 Markdown 排版作为本切片范围。原始工具输出保留，终端控制字符在显示时处理，防止破坏界面。
