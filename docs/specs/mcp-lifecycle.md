# MCP 配置与连接管理（5.C）

日期：2026-11-14。基础 / 高级配置编辑与逐服务连接控制已交付工程验证，现进入真人验收。入口与步骤见 [工作台体验验收](../WORKBENCH-ACCEPTANCE.md)。

## 应用内编辑

打开 /mcp edit（别名 /mcp config），或在 /settings 按 m。

- “切服务”依次选择已有服务与“新增服务”；Tab 选择字段或按钮，Enter 编辑，Ctrl+U 清空，Esc 结束编辑或返回，r 刷新。
- 可填写名称、启动命令、参数 JSON 和环境 JSON。已有名称固定；重命名需新增、删除后重载。
- 参数必须为字符串数组，例如 ["-y","包名"]；环境必须为字符串对象，例如 {"API_KEY":"你的密钥"}。
- 参数和环境值在编辑界面隐藏；后端只返回参数数量与环境键名。已有服务留空保留，[] / {} 分别清空；新服务默认两项为空。
- 更换启动命令、参数或工作目录时，已有非空环境必须重新填写或显式清空，避免把旧凭据传给新程序。
- 按 a 切换高级分组：cwd、timeout、risk、allowed_tools、tool_risks、allowed_origins、browser_actions。列表与映射使用 JSON，开关用 true / false。字段未编辑时原样保留，未知扩展字段不删除。
- 超时范围为大于 0 且不超过 86400 秒，风险为 read/write/exec；工具风险必须位于显式白名单内。开启受控浏览器需要本地来源及受限工具白名单，复用运行时校验。

## 来源、保存与生效

1. 启动配置中指定 VIBE_MCP_CONFIG 时编辑原 JSON 文件，保留 servers / mcpServers / 直接映射格式及其他顶层字段。直接映射中新增名为 servers / mcpServers 的服务时，转为 mcpServers 包装，避免名称与格式字段冲突。
2. 未指定文件时，把内联 JSON 保存到启动器的 .env（VIBE_MCP_SERVERS），保留模型等其他配置。进程环境直接覆盖该变量时只读；先取消覆盖并重启再编辑。启动器会区分来自 .env 和进程环境的值。
3. 保存与删除经过 ApprovalGate，审批只包含路径、服务名、操作和内容摘要哈希；不含参数、环境值。保存前后复核文件版本，文件变化拒绝覆盖。文件以 0600 原子替换，符号链接由用户手动管理。
4. 保存不启动进程、不替换工具。当前进程的内联配置候选会更新，点击重载才用于新连接；删除只改配置，仍在用的连接单独显示；可断开该服务或重载全部后移除。后台 worker 不变。
5. r 刷新保留当前草稿；拒绝、格式错误、保存失败保留草稿；切服务或退出时确认丢弃。成功保存后清除敏感输入，只保留后端的脱敏视图。
6. 外部修改 .env 的来源路径或内联内容仍需重启；手工修改原 JSON 文件可直接重载。应用内保存内联内容是显式更新候选，不会偷偷热读 .env。

## 连接生命周期

- /mcp 查看服务状态和工具数量；面板区分“已连接 / 未连接 / 待重载 / 已删除，仍有连接”。未提交的编辑仍为草稿。
- 面板默认范围为“当前服务”，按 s 显式切到“全部”。重载/断开按显示范围操作；单服务操作不重启或移除其他服务。没有选择服务时不自动退回全部。
- /mcp reload 始终重载全部；面板“重载”读取相应配置并审批候选服务。所选范围全部成功才替换；解析、启动、审批或准备阶段取消失败时保留原连接。
- 重载期间旧服务与候选可能短暂并存，外部服务启动副作用无法回滚。
- /mcp disconnect 始终断开全部；面板“断开”先确认范围，再经审批移除对应前台工具。内置工具保留。空配置全量重载也需要断开审批。
- 任务运行中可查看与编辑草稿；保存、删除、重载和断开由后端互斥拒绝。
- 新风险和受控浏览器逐次审批按新配置注册；候选失败不替换原审批钩子。成功替换/断开时撤销对应工具的旧进程授权和审计钩子，再安装新钩子；其他服务授权不变，持久策略仍适用。
- 清理失败保留句柄，退出时重试；一个旧连接清理失败不阻止其他连接关闭。
- 界面不回显外部异常正文。启动审批仍展示命令和参数，因此凭据应放 env，不能放在命令参数中。
