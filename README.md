# vibe

一个以 TUI 为入口的本地 coding agent，逐步向个人助手工作台发展。当前围绕一个 Agent loop 组织读取代码、修改文件和运行验证；默认使用 Textual，也可通过新增的 Ink 入口连接 Python 后端。

## 现有功能

- **模型接入**：支持 OpenAI-compatible 接口，提供流式输出和本地 fake 模式。
- **编码工具**：读取、搜索和修改工作区文件，执行命令并接收结果。
- **联网检索**：内置 `web_search`，通过免费的 DDGS 返回标题、来源链接与摘要，无需搜索 API Key；搜索词外发前走审批。
- **人工审批**：写入和命令执行前预览与审批，支持授权、撤销、备份和审计。
- **上下文管理**：上下文预算、历史压缩和原文回取，保留任务目标与进度。
- **会话恢复**：保存对话和任务状态，支持重新打开会话与继续任务。
- **外部工具**：通过 stdio MCP 接入外部服务，服务启动与工具调用分别审批。
- **运行记录与评估**：记录 token 用量、费用和工具调用，通过 eval 检查任务产物。

安装、运行和配置见 [使用指南](docs/USAGE.md)。命令以当前用户权限执行，现有审批与超时机制不提供操作系统级沙箱隔离。

Ink 工作台已接通全屏布局、多行输入、Markdown、工具详情、真实执行结果、会话恢复、MCP、分级审批与权限撤销；支持滚轮 / 键盘阅读历史、状态分区与真实预算展示。安装 Node.js 22+ 后执行 `npm --prefix tui ci`，再用 `./run_ink.sh --fake` 体验；`./run_ink.sh --continue` 恢复会话，输入 `/resume` 才继续任务。**默认入口继续保留 Textual，直到 Ink 的开发与实际体验超越 Textual**；eval 仍走 `./run_vibe.sh --eval`。范围与证据见 [功能补齐](docs/specs/ink-parity.md) 和 [阅读与状态展示](docs/specs/ink-reading-state.md)。

## 开发规划

在现有单 Agent 基础上持续迭代，并探索以下方向：

- **多 Agent 协作**：由主 Agent 理解需求、拆分和编排任务，交给子 Agent 执行，再汇总与核对结果。
- **关于你**：在日常任务协作中，逐步整理和展示 Agent 对用户偏好、目标与工作方式的理解，形成可查看、可修正的个人画像，并用于后续任务。
- **界面与全栈学习**：逐步迁移到 TypeScript + React/Ink，再根据实际需求发展浏览器入口，积累交互、状态管理、通信和交付经验。

以上为后续方向，具体设计随实际使用反馈推进，详见 [路线图](docs/roadmap.md)。
