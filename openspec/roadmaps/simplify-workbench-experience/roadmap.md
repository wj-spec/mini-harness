# 工作台体验简化：实施路线图

> v5 · 2026-11-13 · 阶段 1–4 与 5.A/5.B 工程实现完成；真人体验缺口见各阶段验证记录
>
> [整体设计](design.md) · [任务记录](task-log.md)

## 概览

推荐顺序：**回执降噪 → 配置契约与最小模板 → 功能区指引 → 应用内模型设置 → 任务限制与高级设置**。

阶段 1、2 分别交付回执分层和配置基础；用户授权继续后，阶段 3 已细化并实现功能区指引。阶段 4 复用安装目录 .env，已细化保存、检测、应用与恢复边界；阶段 5 已拆为单段限制、goal 总预算、MCP 生命周期三批，5.A/5.B 已交付。

| 阶段 | 成果 | 当前状态 |
| --- | --- | --- |
| 0 基础整理 | 胖猫形象、产品 README、简化启动与模型向导已有工作区成果 | 复用；证据见既有里程碑 |
| 1 回执分层 | 日常对话安静，修改和异常清楚可查 | 代码与工程验证完成；真人体验待确认 |
| 2 配置契约 | 最小示例真实可用，高级项有去处 | 工程实现与验证完成；真人/API/冷安装缺口已记录 |
| 3 功能区指引 | 首次任务和常见情境有明确下一步 | 工程实现与验证完成；真人终端体验待确认 |
| 4 模型设置 | 应用内配置模型，来源与生效范围可见 | 工程交付；真实服务与真人终端体验缺口另列 |
| 5 任务与高级设置 | 单段限制、统一入口与高级状态 | 5.A/5.B 工程完成；5.C 工程就绪，等待真人体验验收 |

阶段 0 不重新申报实施完成；现有 UX 路线图的待验收事项继续由 [MILESTONES](../../../docs/MILESTONES.md) 管理。工程验证与真人验收分别记录；用户明确授权可继续下一阶段，未完成的体验项继续保留，不把未来功能作为当前能力宣传。

### 目标

### 子任务

### 验收标准

- [x] 普通问答与成功只读任务：独立终态回执卡新增数量为 0；答案仍可读，证据仍可达。

- [x] 取消、错误、预算停止说明原因及已保留影响；等待审批/输入不冒充任务完成。
- [x] 自动续段不重复产生终态卡；任务最终摘要保留前段影响，重放/重连不重复追加结果。
- [x] 历史与实时结果归属正确；原始证据可展开；旧数据不从文案推断新的强结论。
- [x] 对话、状态区、检视与 attach 的结果一致；通过相关 Python/Ink 测试及实际 PTY。

- [ ] 真实终端连续问答、修改、失败、恢复旅程由用户体验确认；自动 PTY 已通过，不替代真人体验。

### 目标

### 子任务

- [x] 2.A 交付真实可用的配置分层：配置契约清单、最小 .env.example、高级/开发说明、无效示例处理、向导和帮助入口同步、启动回归。应用内设置不混入本 change。

- [x] CLI/环境覆盖规则、Key 隐藏输入、文件权限、原子保存、取消及失败保留行为通过回归；日志与文档没有真实凭据。
- [x] run_ink.sh / run_vibe.sh 的环境行为未静默改变；README、USAGE 和配置示例一致。

## 阶段 3 · 功能区与情境指引

### 前置条件

- [x] 阶段 1、2 工程已交付；用户授权继续，既有真人体验缺口继续保留。
- [x] 核对首页、命令菜单、审批、计划、检视和任务入口；Ctrl+T 无现有应用内冲突。
- [x] 复用独立面板与底部一行，明确最小终端为 32×12。

### 目标

让用户理解对话、计划进度、检视结果、任务会话、配置帮助，并找到当前需要的下一步；指引可关闭，不打断工作。

### 子任务

- [x] 3.A 实现五区指引、情境提示与可关闭/重开入口，接入真实功能和首页示例，覆盖布局、草稿、阅读、审批与回归验证。

### 验收标准

- [x] Ctrl+T、/guide 和宽屏可点击入口主动打开；没有自动弹出的教程。
- [x] 主区不增加行数；提示可通过 /guide off 关闭、/guide on 恢复，作用域明确为当前工作台实例。
- [x] 示例只填空闲状态的空草稿，不自动发送；已有中文草稿、光标及阅读位置返回后保留。
- [x] 新审批到来自动收起指引，不发送决定；运行控制和计划验收提示继续优先。
- [x] 未提供的能力不显示操作按钮；模型配置指向真实的 ./start.sh --configure。
- [x] 键盘、鼠标、滚动与 32×12、80×24、120×40 布局通过测试。
- [x] Python/Ink 全量及真实 PTY Demo 通过；失败回归及修复记录保留。
- [ ] 用户在常用终端确认指引可发现性、中文阅读和连续工作手感；自动 PTY 不代替真人确认。

### 交付物

五区指引与情境提示、草稿示例、使用说明、阶段实施包及[验证记录](../../changes/implement-simplify-workbench-experience-p3/verification.md)。应用内模型编辑和提示偏好持久化未在本阶段实现。

## 阶段 4 · 应用内模型配置

### 前置条件

- [x] 阶段 2 已核对模型配置消费链，阶段 3 已提供配置帮助入口；用户授权继续。
- [x] 保存沿用安装目录 .env，高级入口仍不隐式加载文件；不引入平行存储。
- [x] 区分普通 OpenAI 兼容、Demo、自定义 provider、额外审计和后台连接。

### 目标

在工作台内查看来源、编辑模型与 Key、显式检测、保存或空闲应用；配置变更不悄悄影响正在运行及恢复的任务。

### 子任务

- [x] 4.A 配置共享读写与来源、审批保存、显式检测、空闲应用、恢复快照核对，以及 Ink 编辑器与回归。

### 验收标准

- [x] /model 与配置帮助均可进入；32×12 至 120×40 可用，返回保留原对话草稿。
- [x] Key 隐藏且不回填；不进入回执、审批参数、审计或快照。更换服务需重新填写 Key。
- [x] 保存通过 ApprovalGate、检查文件版本、原子写入与 0600 权限；失败不改变当前客户端。
- [x] 检测显式确认可能计费，只发固定最小请求，不携带工作区/会话；错误正文不外显。
- [x] 普通 OpenAI 兼容连接空闲应用，主模型与摘要器同步；CLI/环境覆盖优先，运行中仅查看/编辑。
- [x] Demo、自定义 provider、额外审计需保存后重启；后台进程不热切换。
- [x] 新记录包含非敏感模型快照；不匹配时阻止原任务续做并提示原服务/模型/代理。旧记录缺失快照时明确提示兼容边界。
- [x] Python/Ink 全量、三尺寸面板与真实 PTY 保存→返回草稿→审批任务通过。
- [ ] 用户常用终端的真实服务连接、实际模型切换与恢复体验确认；本轮未使用真实 Key 或付费请求。

### 交付物

共享模型配置模块、应用内模型面板、协议与恢复检查、[使用说明](../../../docs/USAGE.md#应用内模型设置)和[验证记录](../../changes/implement-simplify-workbench-experience-p4/verification.md)。检测只证明最小请求成功，模型能力与预算不自动推断。

## 阶段 5 · 任务限制与高级设置

### 前置条件

- [x] 阶段 4 的共享配置读写、来源和审批机制可复用。
- [x] 核对单段运行、task/goal 续段、独立探索与后台进程的作用域。
- [x] 权限面板复用现有能力；MCP 重连与 goal 总预算另拆批次，避免混合生命周期。

### 目标

用统一入口查看并调整任务默认限制，保持运行中和续做任务的限制稳定；高级能力按实际可安全生效的范围逐步接入。

### 子任务

- [x] 5.A /settings 统一入口与四项单段限制：数字编辑、来源、审批保存、空闲应用、续做快照、模型/权限导航和高级状态。
- [x] 5.B goal 总预算：设置分组、审批保存/空闲应用、任务不可变预算、前后台续段门、恢复累计账本与旧记录迁移。
- [x] 5.C 首批：前台原配置重载、审批断开、失败保留旧连接、清理重试与自动回归；[行为与边界](../../../docs/specs/mcp-lifecycle.md)。
- [x] 5.C 基础编辑：原 JSON / .env 来源、凭据保护、审批保存、删除与连接独立；实际本地 MCP 和隔离 PTY 验证。
- [x] 5.C MCP 生命周期与高级编辑：逐服务重连/断开、失败回退、授权清理、高级字段与状态区分已验证；沙箱、通知继续明确重启边界。

### 验收标准

- [x] /settings 与配置指引可进入；键盘和紧凑布局可用，返回保留对话草稿，子面板返回保留设置编辑。
- [x] 步数/token 为整数；时长大于 0；其余 0 表示不限；费用显示单价依赖和估算边界。
- [x] 保存只更新四项限制，经过审批、版本复核和原子写入；应用不写文件且遵守 CLI/环境覆盖。
- [x] 运行中只读和编辑可用，变更互斥；新任务采用新默认，/resume 和 task/goal 续段使用原快照。
- [x] 缺快照明确提示启动时限制；损坏快照阻止执行；运行结束或异常恢复 Agent 字段。
- [x] MCP、沙箱、通知只输出必要状态，不泄露外部参数、环境和 webhook；没有未经验证的热切换。
- [x] Python/Ink 全量与隔离配置的真实 PTY 旅程通过，证据见下。
- [x] 5.B 前后台共享预算快照，达到总上限后手动恢复不重置；真实 worker 和 PTY 通过。
- [x] 5.C 逐服务独立连接、高级字段编辑与隔离验收入口。
- [ ] 阶段 5 真人体验确认，见 [体验验收清单](../../../docs/WORKBENCH-ACCEPTANCE.md)。
- [ ] 用户在常用终端确认连续工作手感；真实远程模型、MCP 和跨平台行为不由本轮 fake PTY 代替。

### 交付物

设置中心、限制配置模块、trace 快照与兼容恢复、[使用说明](../../../docs/USAGE.md#应用内任务限制与设置中心)、[5.A 验证记录](../../changes/implement-simplify-workbench-experience-p5/verification.md)。5.A 与 5.B 分别实施；目标分组、不可变预算和恢复证据见 [5.B 验证记录](../../changes/implement-simplify-workbench-experience-p5b/verification.md)，5.C 工程就绪，等待真人体验验收。
