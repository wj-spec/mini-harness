## P1 · 输入与审批控制

- [ ] 运行 `VIBE_FAKE_DEMO=1 VIBE_TASK_RUNTIME=1 ./run_ink.sh --fake --autonomy ask`。
  - 预期：工具审批出现时，下方有可点击「允许本次」「拒绝」「更多授权」；草稿与中文光标不被审批抢占。
- [ ] 审批中继续逐键输入 `y/s/p/n`、粘贴、按住重复键。
  - 预期：未进入动作区前不会批准；草稿不丢。
- [ ] 点击「允许本次」完成写入；再触发一次并点击「拒绝」。
  - 预期：按钮点击即选中、需要确认才生效（按当前实现记录实际交互）；拒绝后提示可见，`Ctrl+C` 仍能停止。
- [ ] 在 Ghostty 中缩放（Ctrl+= / Ctrl+-）与输入中文候选框。
  - 预期：动作区不把小屏关键信息挤出屏幕；候选框与审批交错不误批准。
- [ ] `/autonomy edits`、`/permissions reset`：确认提示文案说明「本进程授权」与仍有效的档位/策略。

## P8 · 任务与会话导航（含旧会话增量）

- [ ] `/task` 或点击「任务」：分页浏览当前会话任务（目标/状态/worker/待审批数），选择后看准确历史，刷新保留所选任务。
  - 预期：查询不执行、不改记录；返回保留中文草稿与光标；运行中 `Ctrl+C` 仍指向当前运行。
- [ ] 选中任务点击「接入任务」：检查工作台内接入、审批、返回、停止；运行中先等待或停止后切换；离线显示只读。
- [ ] `/sessions` 旧会话增量：
  - 先开两个 `--fake` 会话（各发一条消息后退出），再打开其中一个并输入 `/sessions`。
  - 预期：列表按 test 用途只显示测试会话（不出现真实会话），每页 5 条，标题/更新时间/消息数/最近内容可读；分页按钮可用。

## P9 · 授权解释与撤销

- [ ] 触发一次会申请授权的工具（如 `VIBE_FAKE_DEMO=plan ./run_ink.sh --fake --autonomy ask`），在审批中选择更大范围的授权（「更多授权」里的本会话/工作区档位），让进程内授权出现。
- [ ] 输入 `/permissions`：预期面板显示
  - 当前档位与来源（本进程 CLI / 用户策略默认 / 默认 ask；若有 project 上限则显示被收紧）；
  - 进程临时授权逐条（workspace / session 分开，含工具、目标摘要与「本进程内有效，退出后失效」）；
  - 持久策略规则（[user]/[project]、来源文件、说明进程内不可撤销的原因）；
  - 策略错误时显示「保留上一份策略」原因。
- [ ] 选择一条进程内授权点击「撤销所选」：预期提示「已撤销 …；剩余 N 条进程授权」，列表只剩其他授权；再触发同类工具调用时应重新审批（不是静默放行）。
- [ ] `/permissions reset`：确认 P1 文案与语义不变（撤销全部本进程授权，档位与持久策略不变）。
- [ ] 撤销后立即再发起一次同类工具调用，核对审批提示确实出现；记录撤销前后的行为差异。
- [ ] 可选：写坏 `<workspace>/.vibe/permissions.json` 后重开，确认面板显示策略加载错误且保留上一份策略；恢复文件后刷新面板。

## P10 · 历史定位

- [ ] 跑一段包含多次工具调用与一次失败的长会话（如 `VIBE_FAKE_DEMO=plan ./run_ink.sh --fake --autonomy ask` 后再输入几条任务，或继续真实任务）。
- [ ] 输入 `/find <会话里出现过的词>`：预期面板列出命中与行号；点击「定位」，正文跳到命中行附近（顶部显示回看位置），`Ctrl+End` 回到最新。
- [ ] 输入 `/rounds`：预期按用户轮次列出（序号、终态、目标摘要）；定位到某轮起点。
- [ ] 输入 `/errors`：预期列出工具错误与失败轮次；定位到失败现场，工具卡片与详情仍可看到原始输出。

- [ ] 定位后返回输入：草稿与光标保留；定位过程中不出现新的模型请求或工具执行。
- [ ] 窄屏（32×12）与 80×24 下结果面板可读，`Esc` 返回。
