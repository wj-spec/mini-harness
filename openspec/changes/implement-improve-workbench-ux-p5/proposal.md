用户应该能按中文意图找到已有操作，补齐参数后执行，并知道当前模式与等待原因。当前菜单高亮与 Enter 行为不一致，裸参数命令可能被当成未知命令，帮助和真实处理器存在漂移。

交付范围：共用命令目录、中文查找与分组、子命令发现、明确的 Enter/Tab 规则、参数提示与主题帮助；补齐 attach/merge/stop-workers 入口；对齐可用状态、一次性 act 与粘性 Plan 的提示，并用 80×24 实测减少重复状态占行。继续使用已有命令处理器、审批和版本绑定，不另建插件命令框架。
