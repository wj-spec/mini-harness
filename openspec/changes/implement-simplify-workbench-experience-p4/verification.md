## 交付行为

新 trace 保存非敏感配置快照；普通 /resume、指定 task 续做及计划审阅/修订执行检查已有快照，不匹配则在模型请求前停止。旧记录没有快照时无法恢复未知历史配置，/resume 明确提示兼容边界。

## 实际限制

- 检测单测使用 httpx.MockTransport；真实 PTY 使用 fake 模型和虚构 Key。没有真实 Key、付费请求或远程服务兼容性验证。
- 检测只验证固定最小请求，不证明工具调用、上下文容量或任务质量；预算、价格、固定摘要模型和窗口不会因换模型自动推断。
- Demo、自定义 provider 和额外 LLM 审计客户端需要保存后重启；attach 不暴露模型设置，后台进程保持原配置。
- 新快照只包含 provider、模型、地址、代理和凭据引用，不保存旧 Key；缺失凭据需重新填写。旧记录的未知服务无法补证。
- 编辑器使用末尾追加/删除、Ctrl+U 清空；其草稿在面板关闭时丢弃，成功保存会取消未保存提醒。取消或失败不会覆盖原对话草稿。
- 本机 macOS 自动 PTY 不替代真人常用终端和真实服务验收。阶段 1–3 既有体验缺口继续保留。最终网络分类补丁后再次完成 Python 全量；Ink 未因后端分类补丁重复执行，778/778 是同一最终前端构建的证据。
- 本轮没有改用户现有 .env，没有 commit、push 或归档。下一阶段为任务限制与高级设置。
