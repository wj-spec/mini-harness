# Design
## Context
start.sh 读取安装目录 .env；高级入口仅读取环境。复用现有解析/原子写入，提到 app/runtime 的共享模块，scripts 保留兼容导出。
## Decisions
- 以现有安装目录 .env 保存模型连接，不新增用户/工作区平行配置。启动器仅传配置路径与来源字段名，不传额外凭据。
- /model 的草稿与对话隔离，Key 永不回填；空值表示保留。地址改变需重新提供 Key，防止已有凭据被送到新服务。
- list 可在运行中读取；save/test/apply 走现有互斥命令通道。保存、检测经过 ApprovalGate，预览和审计不含 Key。
- save 带文件版本令牌，审批之后再次核对，避免覆盖外部修改；原子写失败不切换当前客户端。
- test 是固定短消息、输出最多 1 token、无重试的显式请求；错误仅返回分类/状态码。
- apply 不等于 save。只在空闲时替换 provider 与摘要器；保留任务预算。Demo/自定义 provider 或额外审计客户端不做不完整切换，给出重新启动路径。
- 环境/CLI 优先，遮蔽保存项时明确展示。运行/恢复参数记录不含 Key 的模型快照；已有快照不匹配时阻止续做，要求恢复原配置或开始新任务。旧记录无快照明确提示，沿用原兼容入口。
- 后台进程不热更新，attach 不提供设置能力；原 worker 配置保持独立。
## Non-goals
不探测模型目录/窗口能力，不替换权限体系，不实现任务限制与 MCP 设置。
