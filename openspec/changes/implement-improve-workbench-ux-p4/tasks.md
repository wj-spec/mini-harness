## 验收矩阵

| 场景 | 权威结果 |
|---|---|
| 看 A 后另有 B，反馈仍针对 A | A 的准确 Ref 被使用；B 文件不变 |
| 新版/内容修改/错误 hash | 拒绝旧对象，无模型、任务或产物副作用 |
| 原计划与反馈要求更改步骤/约束 | 同 plan_id/v+1 proposed，正文体现反馈，原版字节不变，approval 为空 |
| 模型企图设置身份/批准，或调用写入/命令 | 身份由控制器固定；越权调用拒绝，工作区哈希不变 |
| 重复确认/换请求 ID/重开 | 同操作只有一个初始 Task/segment；查询无 Provider 调用 |
| 保存产物后回执丢失 | 查询找到原新版，不生成 v+2、不再调用模型 |
| 取消/预算/Provider 错误/未提交 | 反馈与来源保留；无占位 proposed；明确暂停/未完成 |
| 修订与批准/执行/其他修订竞争 | 一方取得操作权限，另一方明确冲突；不批准错版 |
| 普通草稿、反馈和工具审批交错 | 草稿不丢，不凭裸字母启动，确认/返回可见 |
| 旧会话与旧命令 | 可查看；新后端修订走准确控制器；旧后端无 capability 不误发新动作 |
