# P2 阅读与刷新约定

## 基线与先固定的验收门槛

机器：darwin arm64 / Apple M5 Pro / Node 24.16.0。运行数据位于 `.vibe/ux-p2-2026-11-08/`。
普通样本：206 个跟踪文件、27 个变化；大差异样本额外跟踪 `large.txt`，周期性变更 5000 行中文内容。
Git 状态读取 30 次 p95 34.06 ms，小文件 diff p95 9.38 ms。

Ink 渲染器 + 真实 Git I/O + 独立线程输入测量（100 次；不含终端合成器/输入法）：

- 普通样本输入 p95 14.88 ms；等行数编辑 3 秒后仍未显示；行数变化一次观测 353.18 ms 后显示。
- 大差异周期更新时输入 p95 486.42 ms，最大 642.15 ms；键输入逐个确认，编辑线程独立运行。
- 同内容计数变化签名未变、A→B→A 输出 `[A, B]` 均已复现。

**下列门槛先于刷新实现锁定，不能在失败后悄悄放宽：**

| 指标 | 门槛 | 测量含义 |
|---|---|---|
| 更新可见最大延迟 | **1500 ms** | 固定样本/健康 Git；磁盘或信号变化到新版本或“有更新”提示可见。等行数更新也必须成立 |
| 刷新期间输入响应 p95 | **100 ms** | 普通和大差异两种样本各 100 次，从独立线程按键入队到可见焦点/阅读状态变化；超时单列，不冒充成功样本 |
| 保留的 diff 文本上限 | **4 MiB（UTF-8）** | 当前展示快照 + 待接入快照的原始文本总和；最多两份，不做全仓库缓存；不是进程 RSS 上限 |

继续保留单次 Git 读取的超时/输出上限；解析/换行也必须受控，不能把同步阻塞从查询移到渲染。大差异、截断和失败要显式说明。测量脚本只记录实测值，结果不满足需修复或显式重审取舍。

## 主区轻反馈

- 复制成功/失败、主题切换等轻提示写入反馈区，保留当前阅读位置、焦点与草稿。
- 完整说明仍进入历史，用户可以主动回到最新；发起新任务等既有导航仍显式切换。
- 读取失败不能藏在历史尾部，当前反馈区须可见。

## 侧栏跟随与固定

- 默认跟随；主动选文件或滚动 diff 后进入“固定阅读”。显示对象包括文件、版本、滚动锚点。
- 固定时后台可更新文件列表及待接入快照，正在读的文字不被替换；显示“有更新”。
- `r` 显式接入所选文件的最新版本；`f` 恢复跟随并选择最近一次成功写入事件对应、仍有效的文件。
- A→B→A 应把 A 放回最近位置；未完成/失败/未知调用不当成成功文件变化。
- 内容身份来自完整读取结果，不能只比较状态和增删行数。无 Agent 信号的外部编辑也需要检测。
- 删除、重命名、变更消失或 Git 失败时，固定旧版必须带过期/错误提示；主动接入后才切换或清空。
- 同一时刻最多一个刷新工作；重复触发合并为后续一次。旧结果不能覆盖新选中的文件，卸载不继续更新。

## 窄栏与缩放

- 40/44/60 列优先显示文件名、当前焦点、固定/跟随和关键键位；不要只用背景色表达选中项。
- 完整路径/重命名源路径可主动查看，返回不改变阅读对象。
- 文件区域和 diff 焦点可区分；窗口尺寸变化保留原始 diff 行的锚点，避免把换行后的屏幕行号当对象身份。
- 标明“本轮触及”和“工作区 vs HEAD”含义不同。P2 仍是一个主会话的侧栏；跨实例身份协议归 P6。
- Ghostty 开栏校准只在创建时发生；不增加持续重置用户比例的逻辑。

设计辅助沿用 `ui-ux-pro-max`：本地检索匹配 All 平台的 Focus States，采用可见焦点原则；CSS/ARIA/触控像素等 Web 规则不套用到 Ink。

## 2026-11-10 反馈增量：记录与对话分离

对话主区只承载任务、回复、工具与审批等会话对象；工作台提示（复制/定位反馈、命令结果、操作异常、后台提示）写入独立记录缓冲，底部提示行显示最新一条与 `/logs` 入口。提示更新不改变阅读位置（不再 `follow` 跳到末尾）；审批/审阅/修订/计划等覆盖层仍优先显示自己的按键提示。`/logs` 为只读面板，保留完整多行内容与滚动，返回不丢草稿。
