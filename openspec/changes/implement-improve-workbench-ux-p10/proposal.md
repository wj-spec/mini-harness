# P10 历史定位

长会话里用户要找的是**旧结论与失败现场**，而不是从头翻页。当前只有滚轮/翻页与 `/copy`，没有搜索、轮次/错误跳转；连续成功只读工具占满正文，真正的结论被推远。U11 要求：用本地搜索和按轮/错误导航定位旧结论，并折叠连续成功只读工具而保留原始执行证据。

第一批完成会话内定位与折叠；第二批补齐跨会话本地检索（`/history`，打开会话并携带 focus）与 rounds 账本深链（`/rounds` 显示验证三态/费用并定位正文）。索引优化、搜索高亮与真人验收仍单列。

## 范围

- `/find <关键词>`：在当前已加载会话正文（渲染行）中做大小写不敏感子串搜索，结果面板列出命中行与位置；↑↓ 选择，Enter 定位到该行并保持回看位置；无结果保留正文并提示缩短关键词。
- `/rounds`：按用户任务轮次列出（轮次序号、终态、目标摘要），Enter 定位到该轮起始行。
- `/errors`：列出工具调用错误（非零退出/调用失败/超时）与失败轮次，按正文顺序排序，Enter 定位到失败现场；原始输出仍在工具卡与详情中。
- 折叠：连续 ≥2 个「只读层（tier=read）且成功」的工具调用折叠为一行摘要（数量与工具计数），`Tab` 选中或 `Ctrl+O` 仍可查看原始调用与输出；非成功、非只读、执行状态未知或旧后端未提供层级的调用不折叠。
- 复用 P2 阅读语义：定位只改变回看位置，`Ctrl+End` 回最新；返回/Esc 保留草稿与光标；搜索与定位不调用模型、不写会话记录。
- 协议：`tool_call` 事件新增可选 `tier`（T0–T4）。旧后端缺省时不折叠（保守），不影响其它功能。

## 预期结果

搜索在 3000 条记录量级的会话上保持交互级延迟（本批实测 p95 见验证记录）；折叠只影响展示，不改 entries、审计或原始输出。真人/真实终端验收与后续批次（跨会话搜索、rounds 账本深链）单列。
