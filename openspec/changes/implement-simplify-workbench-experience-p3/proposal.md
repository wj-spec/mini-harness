# Proposal
## Why
已有首页与快捷键提示分散，新用户难以把对话、计划、检视、任务和设置串成完整流程。落实体验简化阶段 3，让提示就近出现且可关闭。
## What Changes
- 复用底部一行呈现情境下一步，不增加终态卡或强制教程。
- 新增 /guide 与 Ctrl+T 主动打开的五区指引，鼠标与键盘均可操作。
- 示例仅填入空草稿；只导航已有只读入口，不执行任务、审批或设置命令。
- 指引关闭/重开和当前窗口提示开关；审批到来优先显示，返回保留草稿与阅读位置。
## Capabilities
### New Capabilities
- `workbench-guidance`: 不打断工作流的功能区导航与情境下一步。
### Modified Capabilities
无。
## Impact
Ink 的 App、命令注册、首页、独立指引模块与测试；无后端协议和持久化变更。
