# Design
## Context
已有 App 底部 hint、首页示例、ActionButtons、ReadingPane 和独立全屏面板。/help 写工作台记录，不能作为默认新手入口。Ctrl+T 未被现有 App/Composer 占用；Ctrl+K/R/L/O/G/Y 已有用途。参考 ui-ux-pro-max 的可跳过引导与完整键盘导航；终端不套用移动端触摸尺寸规则。
## Goals / Non-Goals
使用现有空间和入口，32×12 至 120×40 可用。不新增设置存储、模型编辑页、后端命令或自动教程。
## Decisions
- guidance 纯函数生成情境文案，结合结构化 outcome 保持“检查通过不等于需求完成”。
- 只在普通主区替换原有一行提示；审批、计划审阅、阅读和错误记录保持优先。
- /guide 或 Ctrl+T 主动打开独立面板，五区以左右键切换，上下滚动、Tab 选动作、Enter 确认、Esc 返回。宽度允许时主区底部显示可点击入口。
- 指引提示默认开启，可在面板或 /guide off 关闭、/guide on 恢复，范围为当前工作台实例；不写配置、不将局部设置冒充全局持久偏好。
- 首页示例在指引对话页按 1/2/3 选择，仅空草稿且空闲可填入。已有草稿明确拒绝覆盖，保留光标。
- 面板导航仅调用已有本地上下文、检视、任务入口；不可用入口不渲染动作并解释原因。模型设置给真实 --configure 命令说明。
- 新审批到来自动关闭指引；不自动重开；Ctrl+C/Ctrl+Q 沿用原有停止/退出语义。
## Risks / Trade-offs
- 同一按键多层处理 → 面板纳入 secondaryPanelVisible，隔离 Composer 与主区输入。
- 窄屏挤占 → 主区不加行；面板 32×12 约束与宽度测试，长内容可滚动。
- UI 本地偏好在切换实例后重置 → 明确当前窗口作用域，持久化留给后续设置机制。
## Migration Plan
无数据迁移。新增命令和本地 UI；关闭提示可回到原有快捷键行。
